Tools

Random things I built for myself, with some help from Claude Code.

Task Breakdown Calendar
This is a mostly-functional calendar, with the main feature being that when you add a "task" due on some particular day, you can give the task a dozen subtasks, and the calendar will automatically distribute those subtasks to be due on days between today and the final due date. No other fancy plugins.
PDF Highlight Extractor
Extracts highlighted text from PDFs using OCR. Useful when the text layer is corrupted or the document is scanned. Supports multiple languages including Hebrew, Arabic, Chinese, and more.
Home Buying/selling Calculator
I didn't love the versions of this that I found online, so Claude helped me build me own. Calculates estimates for US home buying costs and selling gains, with more number flexibility and charts.
